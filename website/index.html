Core Architecture

Engineered Invariants

Six core systems engineered to eliminate layout thrashing, stylesheet collisions, and data loss:

FastDOM Frame Budget (60fps) 100%
Shadow DOM CSS Isolation 100%
Browser Native Footprint (0 External Deps) 98%

W3C Open Shadow DOM Shield

All tool overlays mount inside an isolated Shadow Root. Guarantees 0% CSS leakage into the host document and complete immunity from host styles.

FastDOM Geometry Batching

Batch-schedules geometry reads and visual writes across separate requestAnimationFrame phases to prevent layout thrashing.

Ambient Token Extraction

Calculates host luminance and extracts typographic scale, spatial intervals, and color tokens to synthesize congeneric design variations.

Anti-Occlusion & Smart Dodge

Floating controls automatically flip to prevent obstructing focused nodes. Press H to enter 88% transparent, click-through Ghost Mode.

GoF Reversible Command Stack

Every visual mutation is encapsulated as a bidirectional command with full Undo/Redo history. Hold Spacebar to compare against original styles.

Tailwind & CSS Source Ledger

Maintains a non-destructive ledger of all mutations. Exports clean CSS declaration blocks or equivalent atomic Tailwind CSS classes with 1 click.
