Install AuraCSS

Choose the installation method tailored to your workflow:

Model Context Protocol (MCP) Server

Connect your browser session directly to AI coding assistants via standard JSON-RPC 2.0.

mcp_config.json

Start the Local Bridge:

npm run mcp or node dist/bridge.js --mcp

Listens on http://127.0.0.1:4999 with strict loopback isolation, DNS-rebinding guards, and symlink-safe workspace confinement.

Chromium Extension (Manifest V3)

Zero-popup architecture. Auto-mounts on localhost and activates on-demand on external websites.

  1. Clone & Build: 
    git clone https://github.com/chrey-on/AuraCSS.git
cd AuraCSS
npm install
npm run build
  2. Load Unpacked: Open chrome://extensions/ in Chrome, Edge, or Brave. Enable Developer mode (top-right toggle).
  3. Select Root Directory: Click Load unpacked and select the AuraCSS project root directory.
  4. Toggle Shortcut: Press Alt+A on any web page to activate/deactivate AuraCSS instantly.

Engineered for Zero Bleed & 60fps Precision

Built strictly adhering to modern W3C standards with zero third-party dependencies.

🛡️

W3C Open Shadow DOM

All overlays, docks, and toolbars are mounted inside #auracss-root. Zero host stylesheet pollution and zero external CSS tampering.

⚡

FastDOM 60fps Pipeline

Geometry reads and visual mutations are batch-scheduled across requestAnimationFrame boundaries to prevent layout thrashing.

🎨

Ambient Token Harvesting

Automatically computes luminance and harvests typography scales, border radiuses, and color palettes from the host page.

👻

Smart Dodge & Ghost Mode

Press H to make docks 88% transparent and click-through. Docks automatically flip away from bottom-viewport elements.

↺

GoF Command History

Full Undo/Redo stack (Ctrl+Z/Ctrl+Y). Hold Spacebar to momentarily compare against original baseline styles.

📋

Tailwind & CSS Ledger

Tracks all live element modifications. Formats changes as ready-to-copy CSS declaration blocks or equivalent Tailwind CSS classes.

The Universal MCP Contract

How AI coding agents command AuraCSS using standard Model Context Protocol tools:

Tool 1

auracss_inspect_element

Returns deep visual and spatial context of the selected node: bounding box, computed styles, child hierarchy, and effective background.

Tool 2

auracss_apply_style

Applies live CSS mutations with atomic replacement, isolated @keyframes, and promoted pseudo-class states (hoverState, activeState).

Tool 3

auracss_commit_to_source

Commits visual in-browser mutations directly into local workspace CSS/source files with symlink validation and security confinement.
